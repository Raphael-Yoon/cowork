# 🛡 IT 감사팀 우량 공략주 추출 로직 정의서

본 문서는 IT 감사팀이 트레이딩 시스템(`trade`)에 제공하는 '내일의 우량 공략주'를 추출하는 알고리즘 및 데이터 무결성 검증 로직을 정의합니다.

## 1. 개요
*   **목적**: 주관적 판단을 배제하고 재무 지표, 시장 가격, 최근 뉴스 모멘텀을 결합한 객관적 투자 후보군 도출.
*   **대상**: KOSPI/KOSDAQ 상장사 중 분석 보고서가 존재하는 종목.

## 2. 데이터 소스 (Data Sources)
1.  **재무 데이터**: Google Drive 동기화 기반 엑셀 리포트 (`Report/20260505_latest.xlsx`)
2.  **시장 데이터**: 네이버 금융 실시간 시세 (Scraping)
3.  **심리 데이터**: 네이버 금융 뉴스 검색 (최근 10건의 기사 제목 분석)

## 3. 필터링 로직 (Noise Filtering)
추천 리스트의 신뢰성과 유동성 확보를 위해 다음 항목을 우선적으로 제거합니다.
*   **ETF/ETN 제외**: KODEX, TIGER, ACE, SOL 등 지수 추종 상품 제외.
*   **우선주 제외**: 종목명이 '우', '우B', '우C' 등으로 끝나는 비의결권 우선주 제외.
*   **재무 건전성 미달 제외**: 
    *   **ROE (자기자본이익률)**: 10% 미만 제외 (수익성 미달)
    *   **부채비율**: 150% 초과 제외 (재무 불안정)
*   **상승여력 부재 제외**: 목표가 대비 현재가가 높거나 동일한 종목(상승여력 <= 0) 제외.

## 4. 스코어링 알고리즘 (Scoring Methodology)
본 알고리즘은 **재무 안정성(ROE)**을 기본 축으로 하되, 시장의 **수급(외인/기관)**, **주가 모멘텀**, **뉴스 심리**를 종합 점수화하여 최종 순위를 산출합니다.

**Score = (ROE * 0.4) + (수급 점수 * 0.25) + (주가 모멘텀 * 0.15) + (Upside * 0.1) + (뉴스 심리 * 0.1)**

### 4.1. 상세 가중치 설명
*   **재무(ROE, 40%)**: 기업의 자본 효율성. 15% 이상을 우량주 기본 조건으로 설정.
*   **수급(25%)**: 외국인(15%) 및 기관(10%)의 순매수 유입 강도. **특히 외인 이탈 시 감점 처리.**
*   **주가 모멘텀(15%)**: 52주 저점 대비 회복 탄력성 및 추세 유지력 분석.
*   **저평가(Upside, 10%)**: 목표가 대비 현재 시세의 추가 상승 가능 공간.
*   **뉴스 심리(10%)**: 실시간 보도 기사 내 수주/실적 관련 키워드 스캔 점수.

## 5. 업데이트 주기 및 관리
*   **자동 동기화**: 신규 재무 보고서 입고 시 `sync_news_aware.py`를 통해 DB 자동 갱신.
*   **무결성 검증**: 매일 장 마감 후 실시간 시세를 반영하여 상승여력을 재계산.
