# 🛡 IT 감사팀 우량 공략주 추출 로직 정의서

본 문서는 IT 감사팀이 AI를 통해 산출하는 '내일의 우량 공략주' 추출 기준을 정의합니다.

---

## 1. 개요 및 운영 방식

- **목적**: 주관적 판단을 배제하고 재무 지표, 시장 가격, 수급, 뉴스 모멘텀을 결합한 객관적 투자 후보군 도출.
- **대상**: KOSPI/KOSDAQ 상장사 중 재무 분석 보고서가 존재하는 종목.
- **Python 코드의 역할**: AI가 결정한 결과를 JSON 파일로 저장하는 것에 한정. 분석·판단·데이터 조회는 AI가 수행.

> **[주의] STEP 2·3의 분석(뉴스 검색, 수급 조회, 스코어 산출)은 AI가 네이티브 웹 검색 기능으로 직접 수행한다. 이 과정에 대한 Python 코드를 작성하지 않는다.**

### 전체 프로세스

```
[STEP 1 - 정기] 재무데이터 수집 (data_collect.py)
    DART(재무제표) + 네이버 금융(목표주가 등) 수집 → Excel 파일 → 구글 드라이브 저장

[STEP 2 - 정기] 100개 pool 구성 (AI 수행)
    AI가 구글 드라이브 Excel 직접 접근 또는 파일 다운로드
    → 재무 기반 필터링·스코어링으로 100개 종목 선정
    → pool_save.py → Neon PostgreSQL stock_pool 테이블 저장

[STEP 3 - 비정기] Top 10 선정 (select_top_10.py 실행 또는 AI 수행)
    stock_pool 100개 종목 조회
    + DART API 직접 조회 (최근 30일 공시 — 실행 시점에 실시간 수집, DB 저장 없음)
    + AI 네이티브 웹 검색 (현재가, 수급, 뉴스)
    → 복합 스코어 산출 → 상위 10개 결정
    → Neon PostgreSQL audit_recommendations 테이블 저장
```

## 2. 데이터 소스 (Data Sources)

> **원칙**: Excel은 재무제표(정적) 전용. 주가·수급·52주 범위 등 모든 시장 데이터는 반드시 네이버 금융 웹 조회로 수집한다.

### 2-A. 구글 드라이브 (최신 재무 데이터 원본) — AI가 직접 접근

재무 데이터 Excel의 **원본 저장소는 구글 드라이브**이며, 분석 전 반드시 최신본을 읽어야 한다.  
AI가 구글 드라이브에 직접 접근하거나 파일을 다운로드하여 읽는다. 별도의 Python 코드 없음.

**드라이브 폴더**: `Stock_Analysis_Results`  
**파일 형식**: 구글 스프레드시트 (`.xlsx` 업로드 시 Google Sheets로 자동 변환됨)  
**파일 선택 기준**: `createdTime` 내림차순 기준 가장 최근 생성된 스프레드시트 1개

**폴백 (드라이브 접근 실패 시)**: `cowork/Report/` 폴더 내 `.xlsx` 파일 중 수정 시각 기준 최신 파일을 로컬에서 직접 읽는다.

> **권한 주의**: `drive_sync.py`의 OAuth 권한 범위는 `drive.file` (앱이 생성·업로드한 파일만 접근 가능).  
> 드라이브에 수동으로 업로드된 파일은 접근 불가. 반드시 `upload_to_drive()` 함수를 통해 업로드된 파일이어야 한다.

## 2-B. Excel (정적 재무제표) — 2-A에서 읽은 파일 사용

2-A 절차로 읽은 데이터프레임에서 아래 항목만 사용한다. 그 외 컬럼(현재가, 52주 등)이 있어도 무시한다.

| 컬럼 | 용도 |
| :--- | :--- |
| `종목코드`, `종목명`, `업종` | 종목 식별 및 업종 분류 |
| `ROE` | 수익성 필터링 및 스코어링 |
| `부채비율` | 재무 건전성 필터링 |
| `목표주가` | 업사이드 계산의 분자 기준값 (네이버 금융 집계 증권사 컨센서스, data_collect.py 수집) |

### 2-C. 네이버 금융 (동적 시장 데이터) — AI 웹 검색으로 수집

아래 항목은 반드시 네이버 금융 웹 검색을 통해 실시간으로 가져온다.

| 항목 | 수집 방법 |
| :--- | :--- |
| **현재가** | 네이버 금융 종목 페이지 시세 |
| **52주 최고가 / 최저가** | 네이버 금융 종목 페이지 (날짜에 따라 변동) |
| **외국인 수급 방향** | 최근 N일 순매수/순매도 흐름 (단순 보유율 아님) |
| **기관 수급 방향** | 최근 N일 순매수/순매도 흐름 |
| **뉴스 심리** | 네이버 금융 뉴스 — 최근 10건 기사 제목 분석 |

### 2-D. DART 공시 (실행 시점 직접 조회) — DB 저장 없음

Top 10 선정 시 `select_top_10.py` 내부에서 DART API를 직접 호출하여 최근 30일 공시를 수집한다.  
공시 데이터는 메모리에서만 처리하며 DB에 저장하지 않는다.

## 3. 필터링 로직 (Noise Filtering)

### STEP 2 — pool 100개 선정 (Excel 재무제표 기반)

추천 리스트의 신뢰성과 유동성 확보를 위해 다음 항목을 제거합니다.

- **ETF/ETN 제외**: KODEX, TIGER, ACE, SOL 등 지수 추종 상품 제외.
- **우선주 제외**: 종목명이 '우', '우B', '우C' 등으로 끝나는 비의결권 우선주 제외.
- **ROE 10% 미만 제외**: 수익성 미달.
- **부채비율 150% 초과 제외**: 재무 불안정. (단, 은행·증권·보험 업종은 업종 특성상 제외 적용 면제)
- **목표주가 미보유 제외**: 증권사 컨센서스가 없는 종목 제외.
- pool_score 상위 100개 선정.

### STEP 3 — Top 10 선정 (DART 직접 조회 + 네이버 금융 웹 조회 기반)

- **상승여력 부재 제외**: 네이버에서 조회한 현재가 기준으로 목표주가 대비 업사이드 ≤ 0인 종목 제외.
- **중대 공시 리스크 제외 (Hard Filter)**: 최근 30일 이내에 감사의견 비적정(의견거절/범위제한 한정), 내부회계관리제도 비적정, 또는 대표이사 및 임직원의 배임/횡령 공시가 확인된 종목은 최종 Top 10 선정에서 즉시 강제 배제.
- **단기 하락 추세(역배열) 제외 (Hard Filter)**: 현재가가 5일 이동평균선(MA5) 또는 20일 이동평균선(MA20)보다 아래에 위치한 종목(`ma5_diff <= 0` AND `ma20_diff <= 0`)은 즉시 강제 배제.
- 복합 스코어 상위 10개 선정.

## 4. 스코어링 알고리즘 (Scoring Methodology)

### STEP 2 — pool_score (pool 100개 선정용)

**pool_score = (ROE × 0.4) + (부채건전성 × 0.3) + (목표주가 보유 × 0.2) + (업종 가중치 × 0.1)**

All items normalized to 0~100.

### STEP 3 — score (Top 10 선정용)

**Score = (ROE점수 × 0.30) + (수급점수 × 0.20) + (주가모멘텀 × 0.20) + (Upside × 0.20) + (뉴스심리 × 0.1) + (공시 모멘텀 가감점)**

* **공시 모멘텀 가감점 (최종 점수 보정)**:
  * 최근 30일 이내 대규모 단일판매·공급계약(수주) 및 특허 취득 등 호재성 공시 존재 시: **최종 스코어에 +5점 가산**
  * 최근 30일 이내 소송 피소, 소규모 유상증자(주주가치 희석 우려) 등 악재성 공시 존재 시: **최종 스코어에 -5점 감점**
  * (그 외 중대 공시는 Hard Filter로 사전 필터링됨)

모든 점수 항목 0~100 범위로 정규화.

#### 4-1. 재무 (ROE, 30%)
- 기업의 자본 효율성. 15% 이상을 우량주 기본 조건으로 설정.
- 정규화: ROE 50% 이상을 만점 기준.

#### 4-2. 수급 (20%) — 외국인 12% + 기관 8%
- **반드시 네이버 금융 웹 조회로 수집**한 최근 수급 방향으로 판단한다.
- 판단 기준: 단순 보유율(%)이 아닌 **순매수/순매도 흐름의 방향과 연속성**.
- **외인 이탈 시 감점 처리** (패널티 적용).

#### 4-3. 주가 모멘텀 (20%)
- **반드시 네이버 금융 웹 조회**로 현재가·52주 최고/최저가를 수집한다.
- 산식: `(현재가 - 52주최저가) / (52주최고가 - 52주최저가) × 100`

#### 4-4. 저평가 (Upside, 20%)
- 목표가(Excel 컨센서스) 대비 현재가(네이버 조회)의 추가 상승 가능 공간.
- 산식: `(목표주가 - 현재가) / 현재가 × 100`

#### 4-5. 뉴스 심리 (10%)
- 최근 10건 기사 제목 내 수주·실적 관련 키워드 분석.
- AI가 기사 맥락을 종합적으로 판단하여 긍정·부정·중립 평가.

## 5. 결과 저장 (Output Spec)

### STEP 2 — pool 저장

AI가 100개 pool을 결정한 후 아래 명령으로 Neon PostgreSQL에 저장합니다.

```
python cowork/pool_save.py pool.json
```

저장 위치: Neon PostgreSQL → `stock_pool` 테이블

저장 컬럼:

| 컬럼 | 내용 |
| :--- | :--- |
| `code` | 종목코드 |
| `name` | 종목명 |
| `sector` | 업종 |
| `roe` | ROE(%) |
| `debt_ratio` | 부채비율(%) |
| `target_price` | 목표주가 |
| `pool_score` | pool 선정 스코어 |
| `data_date` | 기준일 (`YYYY-MM-DD`) |
| `updated_at` | 저장 시각 (`YYYY-MM-DD HH:MM:SS`) |

### STEP 3 — Top 10 저장

Top 10 결과는 Neon PostgreSQL의 `audit_recommendations` 테이블에 저장합니다.

```
python cowork/audit_save.py recommendations.json
python cowork/audit_save.py recommendations.json --date 2026-05-10
```

저장 위치: Neon PostgreSQL → `audit_recommendations` 테이블
