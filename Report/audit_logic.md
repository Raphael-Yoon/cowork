# 🛡 IT 감사팀 우량 공략주 추출 로직 정의서

본 문서는 IT 감사팀이 AI를 통해 산출하는 '내일의 우량 공략주' 추출 기준을 정의합니다.

---

## 1. 개요 및 운영 방식

- **목적**: 주관적 판단을 배제하고 재무 지표, 시장 가격, 수급, 뉴스 모멘텀을 결합한 객관적 투자 후보군 도출.
- **대상**: KOSPI/KOSDAQ 상장사 중 재무 분석 보고서가 존재하는 종목.
- **운영 방식**:
  1. **[엑셀]** 재무제표 기반 1차 필터링 → 후보군 압축 (ROE, 부채비율, 목표주가 보유 여부).
  2. **[네이버 웹 조회]** 후보군 종목의 현재가·52주 범위·수급 방향·뉴스 심리 수집.
  3. **[AI 판단]** 2차 필터(업사이드) 적용 후 스코어 산출 및 상위 10개 추천 결정.
  4. AI가 결정한 결과를 JSON 형식으로 정리.
  5. `cowork/audit_save.py`로 `trade/trade.db`에 저장.
- **Python 코드의 역할**: AI가 결정한 추천 결과를 DB에 저장하는 것에 한정. 분석·판단은 AI가 수행.

---

## 2. 데이터 소스 (Data Sources)

> **원칙**: 엑셀은 재무제표(정적) 전용. 주가·수급·52주 범위 등 모든 시장 데이터는 반드시 네이버 금융 웹 조회로 수집한다.

### 2-A. 엑셀 (정적 재무제표) — `cowork/Report/20260505_latest.xlsx`

엑셀에서는 아래 항목만 사용한다. 그 외 컬럼(현재가, 52주 등)이 있어도 무시한다.

| 컬럼 | 용도 |
| :--- | :--- |
| `종목코드`, `종목명`, `업종` | 종목 식별 및 업종 분류 |
| `ROE` | 수익성 필터링 및 스코어링 |
| `부채비율` | 재무 건전성 필터링 |
| `목표주가` | 업사이드 계산의 분자 기준값 (증권사 컨센서스) |

### 2-B. 네이버 금융 (동적 시장 데이터) — AI 웹 검색으로 수집

아래 항목은 반드시 네이버 금융 웹 검색을 통해 실시간으로 가져온다.

| 항목 | 수집 방법 |
| :--- | :--- |
| **현재가** | 네이버 금융 종목 페이지 시세 |
| **52주 최고가 / 최저가** | 네이버 금융 종목 페이지 (날짜에 따라 변동) |
| **외국인 수급 방향** | 최근 N일 순매수/순매도 흐름 (단순 보유율 아님) |
| **기관 수급 방향** | 최근 N일 순매수/순매도 흐름 |
| **뉴스 심리** | 네이버 금융 뉴스 — 최근 10건 기사 제목 분석 |

## 3. 필터링 로직 (Noise Filtering)

추천 리스트의 신뢰성과 유동성 확보를 위해 다음 항목을 우선적으로 제거합니다.

> **1차 필터 (엑셀 기반)**: 재무제표 데이터로 후보군을 먼저 압축한다.
> **2차 필터 (웹 기반)**: 네이버에서 현재가를 조회한 뒤 업사이드를 계산하여 최종 제외한다.

**1차 필터 — 엑셀 재무제표**
- **ETF/ETN 제외**: KODEX, TIGER, ACE, SOL 등 지수 추종 상품 제외.
- **우선주 제외**: 종목명이 '우', '우B', '우C' 등으로 끝나는 비의결권 우선주 제외.
- **ROE 10% 미만 제외**: 수익성 미달.
- **부채비율 150% 초과 제외**: 재무 불안정. (단, 은행·증권·보험 업종은 업종 특성상 제외 적용 면제)
- **목표주가 미보유 제외**: 증권사 컨센서스가 없는 종목 제외.

**2차 필터 — 네이버 금융 웹 조회**
- **상승여력 부재 제외**: 네이버에서 조회한 현재가 기준으로 목표주가 대비 업사이드 ≤ 0인 종목 제외.

## 4. 스코어링 알고리즘 (Scoring Methodology)

**Score = (ROE × 0.4) + (수급 점수 × 0.25) + (주가 모멘텀 × 0.15) + (Upside × 0.1) + (뉴스 심리 × 0.1)**

모든 점수 항목은 0~100 범위로 정규화합니다.

### 4-1. 재무 (ROE, 40%)
- 기업의 자본 효율성. 15% 이상을 우량주 기본 조건으로 설정.
- 정규화: ROE 50% 이상을 만점 기준.

### 4-2. 수급 (25%) — 외국인 15% + 기관 10%
- **반드시 네이버 금융 웹 조회로 수집**한 최근 수급 방향으로 판단한다.
- 판단 기준: 단순 보유율(%)이 아닌 **순매수/순매도 흐름의 방향과 연속성**.
  - 유입 강도: N일 연속 순매수 > 단발 순매수 > 보합 > 단발 순매도 > N일 연속 순매도
- **외인 이탈 시 감점 처리** (패널티 적용).

### 4-3. 주가 모멘텀 (15%)
- **반드시 네이버 금융 웹 조회**로 현재가·52주 최고/최저가를 수집한다.
- 52주 저점 대비 현재가 회복 탄력성.
- 산식: `(현재가 - 52주최저가) / (52주최고가 - 52주최저가) × 100`

### 4-4. 저평가 (Upside, 10%)
- 목표가(엑셀 컨센서스) 대비 현재가(네이버 조회)의 추가 상승 가능 공간.
- 산식: `(목표주가 - 현재가) / 현재가 × 100`

### 4-5. 뉴스 심리 (10%)
- 최근 10건 기사 제목 내 수주·실적 관련 키워드 분석.
- AI가 기사 맥락을 종합적으로 판단하여 긍정·부정·중립 평가.

## 5. 결과 저장 (Output Spec)

AI가 추천 종목을 결정한 후 아래 명령으로 DB에 저장합니다.

```
python cowork/audit_save.py recommendations.json
python cowork/audit_save.py recommendations.json --date 2026-05-10
```

저장 위치: `trade/trade.db` → `audit_recommendations` 테이블  
저장 건수: Score 상위 10개 종목  

저장 컬럼:

| 컬럼 | 내용 |
| :--- | :--- |
| `code` | 종목코드 |
| `name` | 종목명 |
| `current_price` | 현재가 |
| `target_price` | 목표주가 |
| `upside` | 상승여력(%) |
| `roe` | ROE(%) |
| `debt` | 부채비율(%) |
| `reason` | `[업종] 뉴스:{요약} \| ROE {값}% \| 수급 외인{값}/기관{값}` 형식 |
| `created_at` | 저장 시각 (`YYYY-MM-DD HH:MM:SS`) |
| `data_date` | 기준일 (`YYYY-MM-DD`) |
