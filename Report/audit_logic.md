# 🛡 IT 감사팀 우량 공략주 추출 로직 정의서

본 문서는 IT 감사팀이 AI를 통해 산출하는 '내일의 우량 공략주' 추출 기준을 정의합니다.

---

## 1. 개요 및 운영 방식

- **목적**: 주관적 판단을 배제하고 재무 지표, 시장 가격, 수급, 뉴스 모멘텀을 결합한 객관적 투자 후보군 도출.
- **대상**: KOSPI/KOSDAQ 상장사 중 재무 분석 보고서가 존재하는 종목.
- **Python 코드의 역할**: 
  - **[업무 1] Pool 구성**: 구글 드라이브에서 최신 엑셀을 다운로드하여 재무 기반 조건으로 필터링 및 스코어링을 거쳐 100개 종목을 선정한 뒤 DB `stock_pool` 테이블에 직접 저장합니다 (`python cowork/pool_collect.py` 실행).
  - **[업무 2] 추천종목 선정**: 100개 종목 조회 및 뉴스/공시 데이터 수집(`select_top_10.py`), AI의 정성 평가 데이터를 입력받아 공식을 통한 최종 복합 스코어링 및 정렬 수행(`select_top_10.py`), 그리고 상위 10개 종목 DB 적재(`audit_save.py`)를 수행합니다.
- **AI의 역할**: 
  - **[업무 2] 추천종목 선정**: 파이썬이 수집하여 전달해 준 최근 뉴스 및 공시를 읽고 정성적 평가(뉴스 감성 분석 점수 도출, 공시 모멘텀의 호재/악재 여부 판별)만 수행하여 파이썬에 반환합니다.


### 전체 프로세스

```
[업무 1 - 정기] Pool 구성 (100% 파이썬 코드 실행)
    실행 명령어: python cowork/pool_collect.py
    ① 구글 드라이브에서 최신 재무 엑셀 파일 다운로드 (drive_sync.py)
    ② 재무 조건 필터링 및 pool_score 기준 상위 100개 종목 선정 (pool_collect.py)
    ③ 100개 종목을 Neon PostgreSQL stock_pool 테이블에 적재 (pool_save.py)



[업무 2 - 비정기] 추천종목 선정 (파이썬 수집/스코어링/적재 + AI 정성 분석 협업)
    ① pool에 있는 100개 종목 확인 (select_top_10.py - Python)
    ② 각 종목별 뉴스/공시 수집 및 1차 필터링 (select_top_10.py - Python)
    ③ 뉴스/공시 정성적 평가 (AI Prompt - Claude/Gemini)
        - 수집된 최근 뉴스 감성 분석 (0~100점 산출)
        - 공시 모멘텀 가감점 여부 판별 (+5점 / -5점 / 0점)
    ④ 최종 복합 스코어 계산 및 정렬 (select_top_10.py - Python)
    ⑤ 유형별 상위 10개씩 Neon DB 적재 (audit_save.py --type momentum / --type value)
```

## 3. 필터링 로직 (Noise Filtering)

### STEP 1 — pool 100개 선정 (Excel 재무제표 기반)

추천 리스트의 신뢰성과 유동성 확보를 위해 다음 항목을 제거합니다.

- **ETF/ETN 제외**: KODEX, TIGER, ACE, SOL 등 지수 추종 상품 제외.
- **우선주 제외**: 종목명이 '우', '우B', '우C' 등으로 끝나는 비의결권 우선주 제외.
- **ROE 10% 미만 제외**: 수익성 미달.
- **부채비율 제한 적용 (산업별 차등)**: 재무 불안정 기업 제외.
  - **금융업 (은행·증권·보험 등)**: 업종 특성상 부채비율 제한 적용 면제
  - **자본집약적/고부채 업종 (건설·조선·해운·항공·전력/가스 등)**: **300% 초과** 시 제외
  - **일반 업종**: **150% 초과** 시 제외
- **목표주가 미보유 제외**: 증권사 컨센서스가 없는 종목 제외.
- pool_score 상위 100개 선정.

#### 섹터별 대장주 판별 (pool_collect.py 내부 처리)

필터링 완료 후, 동일 `업종` 내 `시가총액` 기준으로 순위를 매겨 대장주 여부를 결정합니다.

| 섹터 내 시총 순위 | `is_sector_leader` | `sector_leader_score` (정규화 점수) |
| :--- | :--- | :--- |
| 1위 | `True` | 100점 |
| 2~3위 | `True` | 60점 |
| 4위 이하 | `False` | 0점 |

> **목적**: pool 내 각 섹터의 유동성·대표성이 높은 핵심 종목을 우선 편입하여 pool이 특정 소형주에 편향되지 않도록 한다. 대장주는 수급 안정성이 높아 추천종목의 신뢰도를 높이는 역할을 한다.  
> **단, 시가총액 데이터 자체가 없는 종목은 `is_sector_leader = False`, `sector_leader_score = 0`으로 처리한다.**

### STEP 2 — 추천종목 선정 (파이썬 수집 데이터 및 AI 분석 기반)


- **상승여력 부재 제외**: 파이썬 스크립트가 수집한 현재가 기준으로 목표주가 대비 업사이드 ≤ 0인 종목 제외.

- **중대 공시 리스크 제외 (Hard Filter)**: 최근 30일 이내에 감사의견 비적정(의견거절/범위제한 한정), 내부회계관리제도 비적정, 또는 대표이사 및 임직원의 배임/횡령 공시가 확인된 종목은 최종 추천종목 선정에서 즉시 강제 배제.
- **단기 하락 추세(역배열) 제외 (Hard Filter)**: 현재가가 5일 이동평균선(MA5) 또는 20일 이동평균선(MA20)보다 아래에 위치한 종목(`ma5_diff <= 0` AND `ma20_diff <= 0`)은 즉시 강제 배제.
- 각 유형별(Value / Momentum) 복합 스코어 상위 10개씩, 총 20개 선정.

## 4. 스코어링 알고리즘 (Scoring Methodology)

### STEP 1 — pool_score (pool 100개 선정용)

**pool_score = (ROE × 0.35) + (부채건전성 × 0.25) + (목표주가 보유 × 0.2) + (업종 가중치 × 0.1) + (섹터 대장주 × 0.1)**

All items normalized to 0~100.

| 항목 | 비중 | 산출 기준 |
| :--- | :--- | :--- |
| ROE | 35% | ROE 50% 이상 = 100점 기준 선형 정규화 |
| 부채건전성 | 25% | 부채비율 낮을수록 높은 점수 (업종별 상한 기준 역정규화) |
| 목표주가 보유 | 20% | 보유 = 100점 / 미보유 = 0점 (Binary) |
| 업종 가중치 | 10% | 성장 업종(반도체·2차전지·방산 등) 가점 |
| **섹터 대장주** | **10%** | **섹터 내 시총 1위 = 100점 / 2~3위 = 60점 / 그 외 = 0점** |

### STEP 2 — score (추천종목 선정용 - 유형별 이원화)

최종 추천종목 선정은 목적에 따라 **Value 스코어**와 **Momentum 스코어**로 이원화하여 산출합니다.

#### A. Value 스코어 (Low Risk)
재무 안정성과 우량한 펀더멘탈을 중시하는 대형 우량주 선정 공식입니다. (국내 주식 시장 특성을 반영하여 배당 점수는 공식에서 제외되었습니다.)
* **공식**:
  > Value Score = ROE점수 × 50% + 수급점수 × 30% + 뉴스심리점수 × 20% + 공시 가감점(+5 / -5) + 대장주 가점(시총 1위 +20점, 2~3위 +15점)
* **상승여력 필터**: **Upside 5% 이상 필수** (5% 미만인 종목은 자동 탈락하며, 스코어 점수 계산 자체에는 반영하지 않음)

#### B. Momentum 스코어 (High Risk)
단기 가격 탄력성과 뉴스/공시 모멘텀을 중시하는 단기 공격형 선정 공식입니다.
* **공식**:
  > Momentum Score = 주가모멘텀점수 × 30% + 수급점수 × 30% + 뉴스심리점수 × 25% + 공시점수 × 10% + ROE점수 × 5%
  *(※ 공시 점수: 호재 공시 시 100점, 무공시/중립 시 50점, 악재 공시 시 0점으로 정규화하여 10% 반영)*
* **상승여력 필터**: **Upside 30% 이상 필수** (30% 미만인 종목은 자동 탈락하며, 스코어 점수 계산 자체에는 반영하지 않음)

* **공시 가감점 및 점수 가이드 (Value/Momentum 공통)**:
  - 최근 30일 이내 대규모 단일판매·공급계약(수주) 및 특허 취득 등 호재성 공시 존재 시: **Value 최종 스코어에 +5점 가산** / **Momentum 공시 점수 100점 부여**
  - 최근 30일 이내 소송 피소, 소규모 유상증자 등 악재성 공시 존재 시: **Value 최종 스코어에 -5점 감점** / **Momentum 공시 점수 0점 부여**
  - 특이 공시가 없을 시: **Value 가감점 0점** / **Momentum 공시 점수 50점 부여**
  - (그 외 중대 리스크 공시는 Hard Filter로 사전 필터링됨)

모든 점수 항목은 0~100 범위로 정규화됩니다.

#### 4-1. 재무 (ROE)
- 기업의 자본 효율성. 15% 이상을 우량주 기본 조건으로 설정.
- 정규화: ROE 50% 이상을 만점 기준.
- **비중**: Value 35% / Momentum 5%

#### 4-2. 수급 — 외국인 + 기관
- **파이썬 스크립트(select_top_10.py)가 수집**한 최근 수급 방향으로 판단한다.
- 판단 기준: 단순 5일 누적 합산이 아닌 **흐름(Flow)**으로 판단. 5일 가중합(최신 거래일에 더 높은 가중치 부여: 45%/25%/15%/10%/5%)이 양수이거나, 가장 최근 거래일에 해당 주체가 순매수한 경우 매수 흐름으로 평가한다. 이를 통해 최신 거래일의 급격한 수급 반전 흐름을 적극 반영한다.
- **외인 이탈 시 감점 처리** (패널티 적용).
- **비중**: Value 25% / Momentum 30%

#### 4-3. 주가 모멘텀 (Momentum 전용)
- **파이썬 스크립트(select_top_10.py)가 수집**한 현재가·52주 최고/최저가를 사용한다.
- 산식: `(현재가 - 52주최저가) / (52주최고가 - 52주최저가) × 100`
- **비중**: Momentum 30% / Value에는 사용하지 않음

#### 4-4. 상승여력 (Upside) — Hard Filter 전용, 스코어 미반영
- 목표가(Excel 컨센서스) 대비 현재가(파이썬 스크립트 수집)의 추가 상승 가능 공간.
- 산식: `(목표주가 - 현재가) / 현재가 × 100`
- **스코어 계산에는 반영하지 않으며**, 최소 진입 허들(Hard Filter)로만 사용한다.
  - Value: Upside **15% 미만** 종목 탈락
  - Momentum: Upside **30% 미만** 종목 탈락

#### 4-5. 뉴스 심리
- **AI(Claude/Gemini)가 직접 판단한다. Python 코드로 구현하지 않는다.**
- 수집된 최근 뉴스 기사 제목을 AI가 해당 종목의 사업 맥락에 맞게 종합 해석하여 긍정·부정·중립을 평가한다.
- 단순 키워드 매칭은 맥락을 무시하므로 사용하지 않는다. (예: "전쟁 우려 해소"의 '우려'는 긍정 맥락)
- `select_top_10.py` 단독 실행 시 뉴스 심리 점수는 60점(중립)으로 고정되며, AI 수행 경로에서 실제 점수로 대체된다.
- **비중**: Value 15% / Momentum 25%

#### 4-6. 추천 유형 분류 기준 (rec_type)
최종 선정된 추천종목은 기업의 재무 상태와 시장 모멘텀 특성에 따라 아래와 같이 **Momentum(momentum)**과 **Value(value)**로 분류됩니다.

* **Momentum (momentum)**:
  - 시장의 단기 수급 및 가격 상승 추세가 강하여 단기 탄력이 기대되는 종목.
  - **판단 기준**: 주가 모멘텀(정배열 상태) 점수가 높거나, 최근 외인/기관의 순매수세가 연속적인 경우. 뉴스 심리가 매우 긍정적이며 체결강도가 강한 종목.
* **Value (value)**:
  - 재무 지표가 우수하여 기초체력(Fundamental)이 튼실하고, 상대적으로 저평가되어 큰 폭의 가격 회복이 기대되는 종목.
  - **판단 기준**: PBR이 낮고(예: PBR 12.0 이하), ROE가 높으며, 목표주가 대비 상승여력(Upside)이 충분한 종목(예: Upside 5% 이상). ※ 대형 우량주는 실적 개선 및 주가 상승으로 PBR이 높아지는 경향이 있어, 기존 3.0 기준에서 반도체, 조선, 방산 등의 핵심 대장주들을 포함하기 위해 12.0 이하로 상한을 완화하여 설정. PBR이 낮을수록 저평가로 우선 선정.

저장 위치: Neon PostgreSQL → `audit_recommendations` 테이블

저장 컬럼:

| 컬럼 | 내용 |
| :--- | :--- |
| `code` | 종목코드 |
